# 入り口デザイン・デフォルトパッケージ（4パターン見本）

サイトの入り口（ホーム）ページの型を用途別に4つ揃えた、納品用の見本一式です。
そのままサーバーへ置くだけで公開できます（静的HTML、外部依存なし、ビルド不要）。

## 構成
- `index.html` — 4パターンの一覧（営業・説明用トップ）
- `a/` — パターンA：アプリLP型（ヒーロー→数字→使い方→料金→声→FAQ→単一CTA）
- `b/` — パターンB：プロフィール集約型（丸アイコン＋名前→先頭ボタン→リンク積み木→最新リンク）
- `c/` — パターンC：実用差し込み型（毎日開く面の最上部に「今日の結果」を差し込む）
- `d/` — パターンD：会員制・秘匿型（見せない設計、約束は1つ、CTAは審査・問い合わせのみ）

## 差し替え箇所
- 各ページ内の文言・数値・名称はすべてサンプル表示です。契約内容に合わせて差し替えてください。
- 色は各ファイル冒頭の CSS（style 内）で変更できます。
- パターンDで数字を出す場合は、裏づけのある実績だけを表示してください。

## 渡し方
- このフォルダ一式を zip にしてそのまま納品できます。
- 公開は GitHub Pages / 任意の静的ホスティング / 通常のレンタルサーバー、いずれでも可。
