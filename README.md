# 入り口デザイン・パッケージ（見本4つ入り）

ホームページの「入り口」（最初に開くページ）の見本セットです。
むずかしい準備はいりません。フォルダを置くだけで、そのままページが開けます。

## まず開くファイル
- `guide.html` — つかいかたの説明（絵つき・この順番で読めば分かります）
- `index.html` — 4つの見本への一覧ページ

## 見本の4パターン
- `a/` パターンA：アプリLP型 — サービス・アプリの紹介に
- `b/` パターンB：プロフィール型 — 個人ページ・リンク集に
- `c/` パターンC：差し込み型 — 占い・天気など毎日変わる内容に
- `d/` パターンD：会員制型 — 会員制・紹介制のサービスに

## 注意
- 文章・数字・名前はすべて見本用の仮の内容です。実際の中身に書き換えてください。
- パターンDで実績の数字を出す時は、ほんとうの数字だけにしてください。
- プログラムの組み立て（ビルド）は不要です。そのまま置けば公開できます。
