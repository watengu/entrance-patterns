DEFAULT PACKAGE — ENTRANCE DESIGN

入り口（ホーム）デザイン
4パターン見本

サイトの「顔」である入り口ページの型を、用途別に4パターンご用意しています。各カードから実際の見本ページを開けます。文章・色・写真は、実際の中身に差し替えて使います。はじめての方は「つかいかた」からどうぞ。

▶ はじめに：つかいかた（guide）を開く

PATTERN A

アプリLP型

ヒーロー → 実績バッジと数字 → 使い方（番号つき）→ 料金 → 利用者の声 → FAQ → 申し込み、の王道構成。

向き：サービス・アプリの製品ページ全般
見本を開く →
 PATTERN B

プロフィール集約型

丸アイコンと名前を主役に、一番見せたいボタンを先頭へ。リンクを積み木式に並べる個人ページの型。

向き：個人ページ、リンク集約、モデル／キャラクターのホーム
見本を開く →
 PATTERN C

実用差し込み型

毎日開く画面の最上部に「今日の結果」を差し込む型。日替わりコンテンツと相性が良い構成です。

向き：占い・天気・今日の一言など日替わりコンテンツ
見本を開く →
 PATTERN D

会員制・秘匿型

全部は見せない。1画面に大きな約束を1つだけ置き、詳細は問い合わせ・審査の奥に置く型。

向き：会員制・審査制サービス（コンシェルジュ、紹介制など）
見本を開く →

このパッケージについて

  • 4つに共通する決まりごと：最初に目立つのは人物（写真やアイコン）、押してほしいボタンは1〜2個に絞る、「更新され続けている感じ」を出す。
  • 渡し方：フォルダ一式をそのまま渡せます。置くだけで公開でき、組み立て作業はいりません。
  • 見本内の数値・声・名称はすべてサンプル表示です。
