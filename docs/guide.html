まず読むページ

このパッケージの、つかいかた

これは、ホームページの「入り口」（最初に開くページ）の見本が4つ入ったセットです。むずかしい準備はいりません。フォルダを置くだけで、そのままホームページとして開けます。

中身はこれだけです

  • 一覧ページ（4つの見本への入口）… index.html
  • 見本A〜D … a / b / c / d の各フォルダ
  • この説明ページ … guide.html

1. どれを選ぶ？（30秒で決まります）

パターンこんな時に形の特徴
A アプリLP型サービスやアプリを紹介したい写真 → 数字 → 使い方 → 料金 → 申し込み、の順に読ませる
B プロフィール型個人のページ、リンク集を作りたい丸いアイコンと名前が主役。リンクを縦に並べる
C 差し込み型占い・天気など、毎日変わる内容があるいつものページの一番上に「今日の結果」を差し込む
D 会員制型会員制・紹介制など、限られた人向け全部は見せない。約束は1つだけ大きく、詳細は審査の先

迷ったら、一覧ページから4つを開いて比べてみてください。

2. 公開のしかた（3通り、どれでもOK）

  1. レンタルサーバー … フォルダの中身をそのままアップロードする
  2. GitHub Pages … このフォルダを置くだけでURLが発行される（無料）
  3. 制作側へ依頼 … このフォルダを渡せば、そのまま使ってもらえる

プログラムの組み立て（ビルド）は不要です。ファイルを開けば中身がそのまま表示されます。

3. 差し替えるところ

  • 文章と数字 … いま入っているのは見本用の仮の内容です。実際の中身に書き換えてください
  • 色 … 各ページのファイル上部（style の中）で変えられます
  • 写真・アイコン … 置きたい画像に差し替えてください（見本では絵文字と図形で代用しています）
パターンDだけ注意：「実績」として数字を出す時は、ほんとうの数字だけにしてください。会員制の型は、盛らないことが信頼になります。

4. こまったら

各見本ページの一番下に、パターン名が書いてあります。「パターン○の、ここを変えたい」と伝えれば、作った側はすぐに分かります。
